# Source and license evidence

The original Raycast JSON to TOON Converter is by **meshal**. Its exact manifest, command and original icon were fetched from raycast/extensions commit `6734d85992290066fd31a7f5bee3cca3d3545a1a`, under `extensions/json-to-toon-converter`. The manifest declares MIT. `fixtures/original/LICENSE` is the genuine repository-root MIT license, copyright 2021 Raycast. An extension-local LICENSE returned HTTP 404; its status/URL sidecar is evidence of that gap, not an invented grant or copyright statement. No independent icon-specific grant was supplied. The icon is retained byte for byte under the repository's available license evidence, with no artwork authorship asserted.

The Tezbar own V1 source is `https://github.com/almatkai/json-to-toon-converter`, commit `f72d105582202089268d31ab0d0314e5f1eef057`. Every tracked file is preserved under `fixtures/own`. Its LICENSE contains literal backslash-n sequences; that exact evidence remains unchanged. `v2/LICENSE` is the same MIT text with line breaks normalized for this port's new code, copyright 2026 almatkai. This normalization does not change the V1 file.

The encoder transcription in `src/lib.rs` derives from **@toon-format/toon 1.3.0**, copyright 2025-PRESENT Johann Schopplich, MIT. Its genuine full license is `fixtures/library/package/LICENSE`. That notice and license must accompany the port. The exact npm tarball, all five extracted members, and version-specific registry response are preserved. The own lock pins 1.3.0 but does not contain a tarball integrity/resolved field for this package; the independently fetched tarball's SHA512 is verified against the saved registry `dist.integrity`. We do not claim this registry response was present in the V1 lock. No newer TOON specification is used as an oracle.

Host fixtures come from Tezbar Git objects `fd300e276356587726566026f072563eb9c34cb1` (beta contracts) and `fe71ca87f21ac4ff31505010c228f8abda0f2a89` (current committed registration/image policy). The host's genuine Apache-2.0 license, copyright 2026 Almat, is `fixtures/beta/LICENSE`. The fixtures are unchanged. Patches are explicitly proposed modifications; the headless harness copies these files and omits unrelated native/registry test modules and their unused test import, with all transformations visible in `tools/prepare_harness.py`. The SDK/common tests are retained. All other adapters and the Tauri type boundary are test stubs, never production substitutes.

Rust crates remain external Cargo dependencies, not archived registry sources. Their exact versions and checksums are in the two Cargo.lock files; Cargo's registry license texts apply to those dependencies. New implementation files are MIT; bundled third-party fixtures retain their original licenses.

`INDEX.json` records each evidence/artifact path, byte count, SHA256 and SHA256 SRI. Original/own/beta/library fixture bytes are immutable. Deterministic command/encoder fixtures were generated by the actual own TypeScript command and locked library with recorded API boundaries. `tests/oracle-native.json` records the three unrepresentable JS outputs as UTF-16 code units; the original JSON oracle remains separately intact.
